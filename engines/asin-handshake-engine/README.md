# ASIN Handshake Engine

A deterministic procedural geometry renderer based on phyllotaxis sampling and radial projection.

## Features

- Golden-angle spiral generation
- Radial projection system
- Fully deterministic rendering
- Configurable parameter space
- PNG export

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Determinism Rule

For identical normalized inputs, the engine is expected to produce identical canvas output.

## Repository Placement

This engine is stored under `engines/asin-handshake-engine/` inside `Holbrook-CP8-HHC` to preserve canonical provenance without fragmenting the GitHub repo strategy.
