# CP8 Tokenizer Gate

The target vocabulary size is 1,024 tokens. A canonical token-to-glyph mapping is not included in this release. A future tokenizer release must provide:

- deterministic token IDs;
- reserved BOS/EOS/PAD/UNK IDs;
- Unicode normalization rules;
- provenance and licensing for every symbol;
- round-trip encoding tests;
- a SHA-256 manifest;
- an immutable training/evaluation receipt.
