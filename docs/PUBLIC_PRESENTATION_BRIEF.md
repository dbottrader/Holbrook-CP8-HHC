# CP8 / ASIN-HHC Public Presentation Brief

**Audience:** builders, reviewers, collaborators, technical friends, public readers  
**Use:** LinkedIn posts, GitHub overview, first-contact explanation, collaborator onboarding  
**Status:** Draft v0.1  

---

## The short version

CP8 / ASIN-HHC is a human-AI workflow system for preserving ideas, code, conversations, and creative artifacts with context, provenance, evidence tiers, and rollback.

It is designed for people who build with AI across many tools and do not want their work to become scattered, untraceable, or overclaimed.

---

## The problem

AI can generate fast, but speed creates a new problem: origin, context, and accountability disappear.

A serious human-AI workflow needs answers to basic questions:

- Who started this artifact?
- Which conversation or file did it come from?
- What changed?
- What was the intent?
- Is it a draft, a symbolic concept, executable code, or reproducible evidence?
- Can we roll it back?
- Can another person understand it without the original creator sitting beside them?

CP8 / ASIN-HHC was built around those questions.

---

## The answer

The framework organizes work through five practical mechanisms:

1. **ASIN metadata** — Anchor, Shape, Intention, Number.
2. **House of Rooms workflow** — Vault, Resonance, Workshop, Bridge, Expansion, Archive.
3. **Codex memory** — structured entries, binary keys, notes, versions, and rollback paths.
4. **Evidence tiers** — clear labels from idea to production.
5. **Agent roles** — AI systems act as builders, archivists, validators, translators, and reviewers under human stewardship.

---

## Why it matters

The useful contribution is not that the project has symbols, glyphs, or dramatic language. Those are part of the orientation layer.

The useful contribution is that the system insists on:

- provenance;
- versioning;
- reversible changes;
- evidence boundaries;
- human context;
- repeatable workflow;
- public/private separation;
- agent contribution tracking.

That is what makes the work durable.

---

## What CP8 / ASIN-HHC is

It is:

- a provenance framework;
- a human-AI co-creation workflow;
- a symbolic orientation system;
- a repository/archive coordination model;
- a project memory system;
- a way to classify outputs honestly.

---

## What CP8 / ASIN-HHC is not

It is not, by itself:

- a claim that symbolic frequencies are measured physical facts;
- a replacement for model-training research;
- a medical, legal, or financial authority;
- a production AI platform unless specific components are deployed and verified;
- a license to publish private data without redaction.

## Best public explanation

CP8 / ASIN-HHC began as a practical answer to a real problem: AI conversations produce valuable ideas, but those ideas often disappear into chat history, screenshots, or disconnected files.

The project evolved into a structured system where each artifact receives context, purpose, a verification label, a stage in the workflow, and a place in the archive. Over time, this became a larger human-AI operating model with agents, repositories, Drive exports, Codex entries, glyph vocabularies, and evidence rules.

The result is a project genome: not only the finished files, but the lineage of how the files came to exist.

---

## The credibility rule

Every artifact should be labeled by what it actually is.

- A symbolic map is a symbolic map.
- A draft is a draft.
- A script is executable only if it runs.
- A claim is evidence-grade only if it has data, code, reproduction, and review.

This boundary is not a weakness. It is the strength of the system.
