## 7. Evidence-Tier Policy

- **Forge / Evidence:** executable code, reproducible hashes, repository commits, verified manifests.
- **Spec / Architecture:** design documents, protocols, schemas, versioned technical specs.
- **Archive / Lineage:** conversations, Takeout files, dated exports, generated reports.
- **Loom / Symbolic:** glyph, ritual, narrative, visual metaphor, spiritual language, identity framing.
- **Legal / Entity:** LLC, operating agreement, sponsorship, IP/legal strategy materials.

This preserves the full creative and technical lineage without overstating any symbolic or speculative artifact as empirical proof.
