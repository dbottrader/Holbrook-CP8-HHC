# CP8 Etymology / Semantic-Graph Notes

**Date:** 2026-09-05

## Research principle

Modern words are not neutral containers. Their meanings drift across time, translation, religion, philosophy, and science. For ancient-text work, the relevant object is therefore not just the modern dictionary gloss but the older **semantic field and relation graph**.

Working model:

`MODERN WORD ← LATER USAGE ← EARLIER TRANSLATION ← HISTORICAL SEMANTIC FIELD ← ROOT / FORM`

The goal is to recover the relational structure before centuries of compression.

## Important distinction

Etymology can identify candidate conceptual continuities and translation losses. It does **not** by itself establish physical identity.

For example:

`ancient lexical sense of plasma = formed / moulded thing`

must not be promoted into:

`ancient authors knew modern ionized plasma physics`.

Likewise:

`breath / wind / spirit semantic overlap`

must not be promoted into:

`spirit = electromagnetic energy`.

Those require separate evidence.

## High-value semantic fields for reconstruction

Rather than searching ancient corpora only for modern technical nouns, reconstruct words and descriptions involving:

- void / emptiness / unoccupied region;
- breath / wind / spirit / moving medium;
- light / luminosity / fire;
- form / formation / moulding;
- becoming / generation / coming into being;
- movement / flow / rotation / pulse;
- separation / division / distinction;
- joining / union / recombination;
- boundary / enclosure;
- source / origin / beginning;
- image / likeness / representation;
- life / animation / soul;
- heaven / upper region / aether;
- transformation / return / renewal.

## Simulation reverse-translation note

The modern phrase `we live in a simulation` carries contemporary computing assumptions that need not belong to older formulations.

Reverse-translation separates:

`SIMULATION → likeness / resemblance / representation`

from modern additions such as:

`external computer + programmer + fake world`.

For ASIN-HHC, potentially better candidate terms include:

`self-representation / manifestation / emanation / instantiation / formation / generation`.

This changes the hypothesis from:

`EXTERNAL COMPUTER → FAKE WORLD`

to a testable conceptual alternative:

`SOURCE → DIFFERENTIATED REPRESENTATION / MANIFESTATION → LOCALIZED EXPERIENCE`.

## Creation-topology candidate

A recurring candidate process to test is:

`UNDIFFERENTIATED / SOURCE`
`→ MOVEMENT / AGENCY`
`→ DIFFERENTIATION`
`→ FORMATION`
`→ ORDER / ORGANIZATION`
`→ LIFE / OBSERVER`

This pattern must be extracted independently from original-language sources rather than read back into them.

## Translation-loss risk

A single English noun may collapse:

`shape + action + relation + metaphor + cultural context + grammar + sound`

into one modern category.

Therefore preserve semantic graphs rather than one-to-one glosses.

Example template:

`TOKEN`
`→ root / morphology`
`→ semantic field {A, B, C, ...}`
`→ local syntactic relations`
`→ attested contextual constraints`
`→ candidate operator(s)`
`→ English gloss only after freeze`

## Integrity rule

Do not ask only:

> What does this word mean in English?

Ask:

> What network of relationships did this word or glyph participate in before successive translation layers compressed it?

Then test whether those relations survive independent reconstruction and controls.
