# ASIN-HHC / CP8 Creator & Provenance Record

## Creator attribution

ASIN-HHC / CP8 is a project created and developed by Dennis Christie through extended human-AI collaboration, iterative prototyping, technical implementation, evidence-led governance, and a large body of dated artifacts.

This record is intended to make attribution auditable rather than rhetorical.

## Provenance principles

1. Creator attribution must be supported by dated artifacts, repository history, screenshots, receipts, releases, deployment records, and other reproducible evidence.
2. AI collaboration must be acknowledged separately from human authorship and decision-making.
3. Third-party prior art must be identified where relevant.
4. Similarity is not automatically evidence of influence.
5. Later implementations or convergence should be evaluated with chronology and evidence rather than assumed copying.
6. Unsupported claims must remain hypotheses until discriminating evidence exists.

## Core methodological contribution

The project formalizes a fixed investigation pipeline:

`ARTIFACT → MEASUREMENT → REPRESENTATION → DECODING → REPLICATION → INTERPRETATION → ORIGIN HYPOTHESIS → CHALLENGE → REVISION`

Claims are separated into:

- OBSERVED
- CONTEXT
- INFERENCE
- TEST
- CONCLUSION

Key governance invariants include:

- Capability != Authority
- No Receipt = No Promotion
- Replay Supersedes Narration
- Specification != Implementation
- Registry Inclusion != Proof
- AI Review != Independent Human Reproduction
- Mythos Has No Runtime Authority
- Reality Retains Veto
- Negative evidence is first-class
- Evidence transfer must be explicit

## Attribution policy

Where the historical record supports Dennis Christie's authorship or origination, that attribution should be stated plainly. Where a component derives from open source, established prior art, another researcher, or AI-generated implementation, that lineage should be preserved explicitly.

The strongest creator record is a transparent chronology that can survive adversarial review.
