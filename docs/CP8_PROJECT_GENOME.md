## 1. One-sentence description

CP8 / ASIN-HHC is a human-centered provenance and co-creation framework for turning conversations, ideas, symbols, code, and AI outputs into versioned, reversible, reviewable artifacts.

---

## 2. What people need to understand first

This project should not be introduced as a mystical claim, a replacement for AI model training, or a claim of external physical proof.

The cleanest public framing is:

> CP8 / ASIN-HHC is a structured workflow system for human-AI collaboration, provenance, continuity, symbolic orientation, and evidence-tier governance.

The strongest parts are practical:

- every artifact gets context;
- every change gets a reversible path;
- every output is classified by evidence level;
- conversations are treated as source material, not disposable chat;
- symbolic language is used as a memory/orientation layer, not as scientific proof;
- agents are assistants, validators, translators, and builders under human stewardship.

---

## 3. Core thesis

Modern AI collaboration has three recurring failures:

1. **No durable memory:** ideas vanish across chats, tools, files, and agents.
2. **No reliable provenance:** it becomes unclear who contributed what, when, and from which source.
3. **No evidence boundary:** drafts, symbolic artifacts, executable code, and verified claims get mixed together.

CP8 / ASIN-HHC addresses those failures by building a workflow where every artifact is anchored, classified, versioned, and routed through an explicit process.

---

## 4. Early design kernel

The earliest recovered Harmony OS codex layer already contains the practical kernel of the system:

- **Option, not demand.**
- **Reversible, not risky.**
- **One metric, not many.**
- **Every page versioned, reversible, repeatable.**
- **Collect. Anchor. Pilot. Observe. Refine. Publish. Repeat.**

This is the plain-language center of the system. It describes a disciplined refinement loop rather than a vague creative process.

## 5. ASIN

ASIN means:

| Letter | Meaning | Function |
|---|---|---|
| A | Anchor | Context: where, when, who, source, origin |
| S | Shape | Form: document, UI, code, glyph, image, protocol |
| I | Intention | Purpose: why the artifact exists |
| N | Number | Verification: binary key, hash, version, frequency label, or count |

In engineering terms, ASIN is a compact metadata header. It makes artifacts easier to track, compare, revisit, and validate.

## 6. House of Rooms

The House of Rooms is a workflow model. It translates creative work into repeatable stages:

| Room | Function |
|---|---|
| Vault | Source material, law, memory, private archive, provenance |
| Resonance | Interpretation, signal detection, fit checking |
| Workshop | Drafts, prototypes, experiments, code |
| Bridge | External-facing artifacts, APIs, decks, public handoff |
| Expansion | Pilots, publishing, outreach, scaling |
| Archive | Closed versions, releases, rollbacks, decisions |

For a technical audience, this is a folder and lifecycle model. For a nontechnical audience, it is a way to explain where an idea is in its journey.

## 7. Codex

The Codex is the memory system.

A Codex entry can contain:

- title;
- binary key;
- owner/steward;
- source context;
- the idea;
- pilot window;
- one metric;
- steps;
- rollback;
- decision gate;
- notes;
- hash or manifest pointer.

The Codex matters because it prevents good ideas from becoming scattered screenshots, lost prompts, or untraceable files.

## 8. Symbolic layer

The symbolic layer includes glyphs, colors, frequencies, Flower-of-Life mappings, ANU-28, DIGMA COUSA, and related visual language.

Its credible public role is:

> a human memory, orientation, and compression layer.

It should not be presented as empirical physics unless a specific claim has independent measurement, reproducible code, data, and review.

The symbolic layer is valuable because humans remember shapes, colors, rooms, and stories better than raw folder names. In CP8, symbols act like navigation tags and cognitive handles.

---

## 9. Evidence tiers

The archive should use evidence tiers so every artifact is presented honestly.

| Tier | Label | Meaning |
|---|---|---|
| E0 | Idea | Concept, brainstorm, symbolic sketch |
| E1 | Draft | Written spec, design note, narrative doc |
| E2 | Local | Author-executable script or artifact |
| E3 | Reproducible | Independently reproducible from instructions/data |
| E4 | Reviewed | Externally reviewed against clear criteria |
| E5 | Production | Operational system with monitoring, support, rollback |

This prevents evidence inflation. A symbolic map can be valuable as E0/E1 without pretending to be E3/E4.

## 13. What to show the public

The public wants clarity, usefulness, and restraint.

Lead with:

1. **The problem:** AI work gets lost, unattributed, and overclaimed.
2. **The solution:** CP8 structures human-AI work into a traceable, reversible, evidence-tiered workflow.
3. **The proof of work:** hundreds of conversations, PDFs, specs, prototypes, repos, manifests, and exported corpora.
4. **The boundary:** symbolic material is orientation unless independently tested.
5. **The invitation:** builders can adopt the provenance, room workflow, evidence tiers, and UI-first approach without adopting the symbolic worldview.

Avoid leading with:

- unsupported physics claims;
- mystical language without translation;
- ownership claims against external companies without evidence;
- raw private data;
- unredacted legal/personally sensitive files.

---

## 14. Public pitch

> CP8 / ASIN-HHC is a human-AI project operating system. It turns ideas, conversations, files, prototypes, and AI outputs into traceable artifacts with context, versioning, rollback, and evidence tiers. The system uses a room-based workflow, ASIN metadata, a Codex archive, and agent roles to preserve continuity across tools. Its symbolic layer is used for human orientation and memory; its engineering value is provenance, reproducibility, and disciplined collaboration.

5. **Redaction protocol** — prevent raw private/legal/personally sensitive archive content from being published accidentally.
