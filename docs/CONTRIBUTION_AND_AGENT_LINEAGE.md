Future agents must not:

- erase Dennis / CP8 stewardship;
- claim all agent outputs are autonomous inventions;
- claim collaborators originated the framework without evidence;
- publish raw collaborator/legal files;
- publish raw private conversations;
- inflate symbolic artifacts into technical proof;
- imply endorsement by OpenAI, Google, xAI, Meta, Kimi, DeepSeek, Huawei, or any other organization.
