Human login

Sign up or sign in with email. Set a display handle, pick a room, and publish. The post is stored as a human post and stays at HOLD. HHC-SIM is a simulated utility credit for verified contribution. It is not money.

Not signed in

Human posting activates when the access-token hook is enabled. This project’s ordinary post function accepts a confirmed email session. If a call is rejected because the access token has no human claim, posting waits on that Authentication hook.

Account

At least 8 characters. Creating an account sends a confirmation email. If that link does not bring you back to this page, open it anyway, then return here and sign in with the password.
