Sovereign open-source AI, checked in public.

Proof-of-Work Commons is a way to run open-source AI on GPUs that volunteers offer. Someone posts a bounty. A worker claims it. Other people check the result. A receipt records what happened. The credit paid for that work is simulated. It is called HHC-SIM. It is not a token, and it is not money.

Built by Dennis Christie (@dbottrader). Profile: moltbook.com/u/asinhhc.

Hold. This site is a public demonstration and a replay you can run yourself. It does not promote the system to production, and it does not give HHC-SIM monetary value.

How it works

  1. A bounty is posted. The publisher sets a price in simulated HHC-SIM credits and escrows that amount for one piece of work.
  2. A GPU worker claims a fenced lease. Until the lease ends, a second worker cannot take the same bounty. When the lease ends, someone else may claim it.
  3. Verifiers check the result. Two verifiers look at the work. They are not the publisher, not the worker, and not each other.
  4. Escrow settles 90/5/5. If both verifiers pass, the worker receives 90% and each verifier receives 5%. If either verifier fails the work, the publisher is refunded in full. A verifier who voted pass still receives nothing on a failed job.
  5. A receipt closes the step. Each step is hashed and linked to the step before it. The proof replay publishes that chain, the file hashes, and the eight launch gates.

Amounts are whole milli-credits. 1000 milli-credits equal 1.000 HHC-SIM. When 90/5/5 does not divide the price evenly, the leftover milli-credits go back to the publisher. They are not paid to a worker, and they are not created as new credit.

Join the GPU mesh

The inference software in this project is gpu-mesh/. It is a coordinator plus workers. A free CPU worker can serve the open-weight model SmolLM2-360M-Instruct (Apache-2.0), downloaded when the worker starts. mock-tiny is a stub used to exercise the path. It is not that model. This Pages site does not host the mesh.

HHC there is a simulated utility credit for verified contribution. An amount is written down only after a second worker spot-checks the reply. It is not sold, and it pays no return.

The join steps are gpu-mesh/docs/FREE_TIER.md. A volunteer with an NVIDIA GPU installs Ollama, pulls an open weight, and starts the worker with the coordinator's invite. The same guide has the one-time Hugging Face Space steps for an always-on free CPU demo. That demo is not deployed from this site.
