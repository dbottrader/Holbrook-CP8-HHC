Lend your machine to open AI. Get a receipt for every job.

Your node replays AI jobs other volunteers ran. When two independent replays match, the work is signed, receipted, and credited to everyone who did it.

  1. Run one command. On Linux x86_64 or Windows WSL2: 
    curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/join.sh | bash
    To name where your credits settle, add an EVM address: 
    curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/join.sh | bash -s -- --payout-address 0xYourEvmAddress
  2. Watch it check itself. Seven steps print PASS or stop with FAIL: the pinned Ollama runtime (sha256), the model weights (sha256), the model digest 29ef26c5, and a replay of public job job_17da8f18d97f that must reproduce its output hash exactly. A machine that cannot reproduce it is not started, which keeps honest work from being scored as a disagreement. The one-time download is about 2 GB, so allow a few minutes.
  3. Earn on verified work. The node registers and runs in the background. It replays other nodes' jobs and runs its own. Find your node id on the live stats and each receipt on the proof page. Stop any time with bash ~/.asin-hhc/stop.sh.

What you need

  • Linux x86_64 with AVX2 (almost any CPU since 2013), or Windows 10/11 with WSL2.
  • About 2 GB of free disk during install (0.7 GB after), 2 GB of free RAM, curl, and Python 3.11+ (if Python is missing, the script fetches uv into its own folder).
  • No Docker, no sudo, no account, no invite. Everything lives in ~/.asin-hhc.

Why a fixed CPU runtime, even on a GPU box

Verification here means a second machine reruns the job and must get the same output, bit for bit. Greedy output is not identical across hardware kernels. On our own test box, AVX-512/AMX kernels answered Mesh where AVX2 kernels answered mesh, and the mesh scored that as a disagreement. So every verifier runs one canonical runtime: Ollama 0.40.15 with only its AVX2 CPU backend, on a private port that never touches your own Ollama. A GPU-canonical profile comes next, once GPU-to-GPU replays are proven to match.

What a job earns

  • HHC is a utility credit for verified contribution. It is not sold and it pays no return.
  • A verifier earns the same credit whether it agrees or disagrees, so there is no reason to fake agreement. A verifier commits the hash of its output before the hub reveals the worker's.
  • A job settles as HHCW on Base Sepolia after two distinct verifiers, neither of them the worker, agree. A disagreement goes to one tiebreaker.
  • New nodes hold credit until they are 7 days old and have 3 verified jobs.
  • HHCW 0x24a7…db5d · Settlement 0xdfFE…bcCA

Before you pipe anything into bash

Read it first: join.sh. Or download it and run bash join.sh --dry-run to see the plan and pins without changing anything. The node token stays in ~/.asin-hhc/node.json with mode 600. The full guide is CONTRIBUTING-GPU.md.

Other setups

  • macOS and ARM: not a verifier yet, because their replays are not proven to match. Watch the guide for updates.
  • Docker and GPU worker kit (advanced): gpu-mesh/deploy/join/README.md. It serves other models, which the current verifiers do not replay.
