Run one command, do verified work for open AI

The command starts one Docker image. That image runs the GPU Mesh worker. A visible NVIDIA or AMD GPU selects Ollama on that GPU. A machine with no GPU runs llama.cpp and SmolLM2-360M-Instruct. The public coordinator is already filled in. No account and no invite are required.

HHC is a utility credit for verified contribution. It is not sold and it pays no return. A verified job settles on Base Sepolia as HHCW after two distinct verifiers agree. Pass --payout-address 0x… to name the EVM address that receives this node's share. A worker cannot verify its own job.

Linux and macOS

curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/install.sh | bash

That joins https://ecenvlwyenpakrxfuqup.supabase.co/functions/v1/gpu-mesh. The published open invite is open. Registration is rate-limited. The installer detects the GPU. Flags:

  • --gpu requires a visible NVIDIA or AMD GPU. NVIDIA uses --gpus all and the CUDA Ollama image. AMD uses ollama/ollama:rocm with /dev/kfd and /dev/dri. If the NVIDIA driver is installed and nvidia-container-toolkit is not, the script prints the install commands and stops.
  • --cpu runs llama.cpp and SmolLM2-360M-Instruct even when a GPU is visible.
  • --backend ollama or --backend llamacpp picks the inference runtime. With no flag, a GPU selects Ollama and a machine with no GPU selects llama.cpp.
  • --payout-address 0x… is the EVM address for this node's HHCW. The check is unchanged: 40 hex characters, not the zero address.
curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/install.sh | bash -s -- --payout-address 0xYourEvmAddress --gpu
curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/install.sh | bash -s -- --cpu

From a checkout, Compose is gpu-mesh/deploy/join/docker-compose.yml. The NVIDIA profile sets deploy.resources.reservations.devices with driver nvidia and capabilities [gpu]. The ROCm profile uses ollama/ollama:rocm. The published image is ghcr.io/dbottrader/holbrook-cp8-hhc/gpumesh-join.

Windows

Install Docker Desktop and leave it running. PowerShell:

docker run -d --name gpumesh-join --restart unless-stopped -e GPU_MESH_COORDINATOR=https://ecenvlwyenpakrxfuqup.supabase.co/functions/v1/gpu-mesh -e GPU_MESH_BACKEND=llamacpp -v gpumesh-join:/var/lib/gpumesh ghcr.io/dbottrader/holbrook-cp8-hhc/gpumesh-join:latest

The published image also defaults to that coordinator, so GPU_MESH_COORDINATOR can be omitted after the image that contains the default is current. Override it when you run your own coordinator.

For Ollama, install it from ollama.com/download/windows, pull a weight, and set GPU_MESH_BACKEND=ollama with GPU_MESH_OLLAMA_HOST=http://host.docker.internal:11434. The longer notes are in the repository file gpu-mesh/deploy/join/WINDOWS.md.
