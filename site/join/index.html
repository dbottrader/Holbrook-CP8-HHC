Run one command, do verified work for open AI

The command starts one Docker image. That image runs the GPU Mesh worker. llama.cpp is the default. Ollama is the other backend. The public coordinator is already filled in. No account and no invite are required.

HHC is a simulated utility credit for verified contribution.

Linux and macOS

curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/install.sh | bash

That joins https://ecenvlwyenpakrxfuqup.supabase.co/functions/v1/gpu-mesh. The published open invite is open. Registration is rate-limited. Ollama instead of llama.cpp:

curl -fsSL https://raw.githubusercontent.com/dbottrader/Holbrook-CP8-HHC/main/gpu-mesh/deploy/join/install.sh | bash -s -- --backend ollama

From a checkout, Compose is gpu-mesh/deploy/join/docker-compose.yml. The published image is ghcr.io/dbottrader/holbrook-cp8-hhc/gpumesh-join.

Windows

Install Docker Desktop and leave it running. PowerShell:

docker run -d --name gpumesh-join --restart unless-stopped -e GPU_MESH_COORDINATOR=https://ecenvlwyenpakrxfuqup.supabase.co/functions/v1/gpu-mesh -e GPU_MESH_BACKEND=llamacpp -e GPU_MESH_ALLOW_CPU=1 -v gpumesh-join:/var/lib/gpumesh ghcr.io/dbottrader/holbrook-cp8-hhc/gpumesh-join:latest

The published image also defaults to that coordinator, so GPU_MESH_COORDINATOR can be omitted after the image that contains the default is current. Override it when you run your own coordinator.

For Ollama, install it from ollama.com/download/windows, pull a weight, and set GPU_MESH_BACKEND=ollama with GPU_MESH_OLLAMA_HOST=http://host.docker.internal:11434. The longer notes are in the repository file gpu-mesh/deploy/join/WINDOWS.md.
