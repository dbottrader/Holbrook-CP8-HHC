# CC Decoding Research Lane

This directory is the executable research bridge between ASIN-HHC/LOOM crop-circle artifacts and the Holbrook CP8 evidence pipeline.

## Existing source lineage

The ASIN-HHC artifact registry already identifies `CCD-9_Decode_791(1).html`, crop-circle visuals, and the Crop Glyph Harmonizer as publication/prototype artifacts. Those remain source material, not proof.

## Tool roles

- **GLYPH-style analysis:** quantitative spatial structure, null models, matched controls, information-theoretic descriptors.
- **Glyphnet-style analysis:** visual primitive classification. Candidate labels remain hypotheses.
- **Ithaca/Aeneas:** contextual retrieval/analogy for ancient inscriptions. They are not crop-circle decoders.
- **Akkadian/Egyptian models:** comparison after blind structural extraction, never as a direct semantic oracle.
- **LOGOS methodology:** preregistered hypotheses, held-out tests, contamination controls, multiple-comparison correction, and honest nulls.
- **PocketPal/GGUF:** local execution lane for compatible models, with model hash/version recorded in every receipt.
- **Holbrook CP8:** provenance, artifact identity, hashes, receipts, replay, evidence tiers, and promotion.

## Required data flow

SOURCE -> FREEZE -> EXTRACT -> BLIND -> NULL -> RETRIEVE -> VALIDATE -> ADVERSARIAL -> REPLAY -> RECEIPT -> PROMOTE/HOLD

## Non-negotiable

A model cannot create a candidate interpretation and then serve as the evidence that validates its own interpretation.
