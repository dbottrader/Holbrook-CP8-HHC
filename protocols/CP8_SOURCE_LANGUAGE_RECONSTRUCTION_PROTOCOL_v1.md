# CP8 Source-Language Reconstruction Protocol v1

**Date:** 2026-09-05  
**Status:** DRAFT / FALSIFIABLE  
**Purpose:** Reconstruct ancient texts from the earliest recoverable linguistic layer before comparing them with modern English translations or ASIN-HHC hypotheses.

## Core rule

**English stays out of the decoding loop until the source reconstruction is frozen.**

Conventional translations are controls, not starting substrates.

## Pipeline

`ORIGINAL INSCRIPTION / MANUSCRIPT`
`→ SCRIPT / GLYPH INVENTORY`
`→ SEGMENTATION`
`→ MORPHOLOGY / ROOTS`
`→ HISTORICAL SEMANTIC FIELD`
`→ SYNTAX / GRAMMATICAL RELATIONS`
`→ DISCOURSE / PARALLEL STRUCTURE`
`→ OPERATOR / RELATION GRAPH`
`→ FROZEN SOURCE RECONSTRUCTION`
`→ CONVENTIONAL TRANSLATION COMPARISON`
`→ CROSS-CORPUS COMPARISON`
`→ PHYSICAL / METAPHYSICAL HYPOTHESES`

## Evidence objects

For every source token or glyph record:

- source witness / manuscript ID;
- date range and provenance confidence;
- exact script form;
- transliteration;
- lemma / root candidates;
- morphology;
- grammatical role;
- historical semantic range;
- attested cognates / parallel usages;
- local syntactic dependencies;
- ambiguity set;
- candidate operator(s), if justified;
- confidence;
- evidence state: OBSERVED / REPORTED / DERIVED / INFERRED / HYPOTHESIS / HOLD.

## No premature collapse

Do not reduce broad semantic fields to one English word before contextual constraint.

Example representation:

`RUACH = {wind, breath, spirit, moving air, respiration-related sense ...}`

not immediately:

`RUACH = SPIRIT`

Likewise, do not reverse-bias the text into a preferred modern concept:

`RUACH ≠ ENERGY` by default.

`PLASMA_ancient ≠ PLASMA_modern` by default.

`VOID_ancient ≠ QUANTUM_VACUUM` by default.

## Divine-term rule

Do not normalize all divinity terms into a universal English token `GOD`.

Preserve:

- morphology;
- singular/plural agreement;
- grammatical agency;
- proper-name vs category distinctions;
- local cultic / literary function;
- semantic range;
- manuscript variation.

Cross-tradition comparison must occur at the level of **relations, actions, and process topology**, not by asserting that deity labels are synonyms.

## Manuscript-witness rule

Where multiple witnesses exist, do not manufacture one pristine original.

Create branches:

`WITNESS_A → reconstruction_A`
`WITNESS_B → reconstruction_B`
`WITNESS_C → reconstruction_C`

Then record convergence and divergence.

## Operator-graph layer

After linguistic reconstruction, represent only relations supported by the text. Candidate operator vocabulary may include:

- SOURCE / ANCHOR
- SEPARATE / DIFFERENTIATE
- JOIN / COUPLE
- MOVE / FLOW
- BOUND / ENCLOSE
- TRANSFER
- TRANSFORM
- ITERATE / CYCLE
- RETURN
- INTEGRATE
- EMERGE

Do not force every text into this vocabulary. Add operators when source structure requires them; remove operators when unsupported.

## Blind cross-corpus rule

Each corpus is reconstructed independently.

Suggested sequence:

1. Hebrew creation material;
2. Egyptian creation texts;
3. Mesopotamian creation texts;
4. Greek / Hermetic texts;
5. Vedic / Sanskrit creation material;
6. unrelated ancient control corpora;
7. synthetic and shuffled controls.

The reconstruction team for one corpus should not use the candidate topology derived from another corpus to choose ambiguous lexical meanings.

## Frozen hypothesis test

Before comparison, preregister candidate topology such as:

`H_SOURCE = ONE → DIFFERENTIATION → RELATION → MOTION / TRANSFORMATION → FORMATION → INTEGRATION / EMERGENCE`

Then score each independently reconstructed corpus against it.

A corpus may:

- support the full topology;
- support a partial topology;
- contradict it;
- be underdetermined.

Contradictions are retained as evidence.

## Controls

Use:

- established scholarly translations only after freeze;
- unrelated ancient texts;
- shuffled token orders;
- synthetic texts engineered to match superficial vocabulary but not syntax;
- modern esoteric constructed texts;
- random geometry-matched glyph controls where applicable.

If the same operator interpretation fits controls equally well, the hypothesis weakens.

## Translation output format

Every final passage should expose parallel layers:

1. **Source text**
2. **Literal morphological reconstruction**
3. **Semantic-field reconstruction**
4. **Syntactic / operator graph**
5. **Candidate ASIN reading**
6. **Conventional English translation(s)**
7. **Differences introduced by translation**
8. **Alternative readings**
9. **Confidence / HOLD notes**

## Falsification

The ASIN-HHC source-language hypothesis weakens if:

- semantic/operator convergence disappears when English translations are withheld;
- unrelated controls fit equally well;
- candidate operators depend primarily on ambiguous lexical choices;
- independent philological reconstruction consistently rejects the proposed relationships;
- cross-corpus convergence results from shared translator vocabulary rather than source structure.

It strengthens—not proves a common ontology—if independent reconstructions converge on constrained relation / process graphs that survive controls and do not require selective lexical choices.

## First recommended fixture

**Genesis 1:1–5** from source Hebrew, with multiple textual witnesses where relevant.

Freeze the source-level reconstruction before viewing or scoring modern theological translations.

**Retrieval before judgment. Replay supersedes narration. Reality retains veto.**
