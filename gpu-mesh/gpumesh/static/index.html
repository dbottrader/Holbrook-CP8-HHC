Live nodes

A node is a Linux process with an auth token. It heartbeats its GPU, VRAM, and the models it can run, then pulls jobs. Quarantine means canaries or spot-checks went bad often enough that the scheduler stopped offering it work.

Put a GPU on the mesh

The installer creates a system user named gpumesh and a systemd service that drops privileges. The agent never opens an inbound port. It detects NVIDIA with nvidia-smi, talks to Ollama or vLLM on localhost, and pulls chat jobs from this coordinator.

… nodes online right now.

  1. A Linux machine with an NVIDIA driver. Ollama or vLLM has to already be serving an open-weight model you pulled yourself. That GPU worker does not download weights. The CPU llama.cpp command below does download one pinned open GGUF. Closed models are not part of this mesh.
  2. Install the agent with one line. Root is used to create the user and the unit. The running process is gpumesh, with NoNewPrivileges and a read-only system.
  3. Watch this board. The node shows up after its first heartbeat. A finished job writes a receipt. Spot-checks re-run a sample on a second node; known-answer canaries run even if you are the only machine online.

CPU open-weight worker

      
This serves SmolLM2-360M-Instruct (Apache-2.0) through llama.cpp. The pinned GGUF is downloaded on first start and is not mock-tiny. HHC is a simulated utility credit. An amount is recorded only after a second worker spot-checks the same model id.

      

      

      
What you are not signing up for

      
There is no payout, no wallet, and no token. Credits cannot be transferred. A bad canary or a temperature-0 spot-check that disagrees costs credits and, after repeated failures, quarantine. Prompts are kept only long enough to re-run a spot-check, then deleted. The node executes chat messages through your local model server. It does not shell out with the prompt.

    

  

  

    
Compute credits are simulated accounting. They are not money, not a token, and they cannot be traded or redeemed.
