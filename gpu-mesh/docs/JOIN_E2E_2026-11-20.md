## Root cause, reproduced locally against the same request (`gpumesh_node.runtime.ollama_payload`)

| Runtime on this box | Output, 3 runs each |
|---|---|
| Ollama 0.40.16, all CPU backends (picks AVX-512/AMX) | `Mesh` |
| Ollama 0.40.15, all CPU backends | `Mesh` |
| Ollama 0.40.15, num_thread 1, 2, 4, 8 | `Mesh` |
| Ollama 0.40.15, only `libggml-cpu-haswell.so` (AVX2) | `mesh` |

The Ollama version and thread count did not change the answer. The CPU kernel family did.
